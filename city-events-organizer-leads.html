City Event Organizer Leads: Emails, Phones, Venues

How it works

Event organizer and venue leads with emails, phones and websites from official open city event feeds (Paris, Nantes, Helsinki, New York). Filter by date, keyword, category and contact. Beta.

Input options

FieldNameRequiredWhat it does
sourcesCity feedsnoWhich official open event feeds to read. Leave empty for all four. NYC rows name the permitting city agency, not a private organizer, and carry no contact details.
modeOutput modenoEvents returns every matching event. Organizers groups events into one lead per organizer, with event count, next date, categories and sample events.
keywordsKeywordsnoMatch event title, tags and venue, e.g. concert, festival, conference, exhibition. Any keyword matches. Use the local language for local feeds, e.g. concert, exposition, spectacle.
categoriesCategoriesnoKeep only events whose category or tags contain one of these words, e.g. Concert, Theatre, Sport. Case-insensitive.
cityCity or area containsnoOptional. Keep events whose city, borough or district contains this text, e.g. Espoo, Brooklyn, Nantes.
dateFromDate from (YYYY-MM-DD)noEarliest event date. Defaults to today.
dateToDate to (YYYY-MM-DD)noLatest event date. Defaults to Days ahead from Date from.
daysAheadDays aheadnoWindow length when Date to is empty.
mustHaveContactOnly leads with a contactnoKeep only rows with at least one of email, phone or website.
mustHaveEmailOnly leads with an emailnoKeep only rows with a published organizer email.
maxItemsMax resultsnoTotal rows to deliver, split evenly across the chosen feeds. You pay per row delivered.

Limits, stated plainly

Public data only, no login. Fields a source does not publish come back empty rather than guessed. Coverage and freshness follow the underlying public source.
