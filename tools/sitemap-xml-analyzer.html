Sitemap XML Analyzer

Paste a sitemap.xml and get URL counts by section, duplicates, stale lastmod dates and format problems, all in your browser.

Browsers block one site from fetching another site's sitemap, so open your sitemap URL, copy the XML (Ctrl+A, Ctrl+C) and paste it here. It handles a normal sitemap (urlset) and a sitemap index. It does not fetch or check whether each URL actually loads.
