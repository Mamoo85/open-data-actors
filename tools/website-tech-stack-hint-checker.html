Website Tech Stack Hint Checker

Paste a page source and see which CMS, frameworks, analytics and widgets it uses, detected in your browser.

Browsers block one site from fetching another site's pages, so this tool cannot fetch a URL for you. Open the site, press Ctrl+U (View Source), copy everything, paste it below. Detection is by signature strings in the HTML, so it shows hints, not proof.

Need this at scale?

To check hundreds of live sites without pasting source by hand, website-tech-stack-detector on the Apify Store runs it in bulk and returns structured data. This page is free and stays free: it runs entirely in your browser, makes no network requests, stores nothing and has no tracking.
