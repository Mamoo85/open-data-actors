On-Page SEO Audit from HTML

Paste a page's HTML source and check title, description, headings, canonical, images, social tags and structured data in your browser.

Browsers block one site from fetching another, so open the page, press Ctrl+U (View Source), copy everything and paste it here. It checks what is in the HTML you paste. It cannot measure speed, rankings, backlinks, or content rendered by JavaScript after load.
