PyPI Package Stats and New Releases Tracker

How it works

Get PyPI package stats and new releases: latest version, release dates, release cadence, download counts and an activity score for every package you list. Uses the public PyPI and pypistats.org JSON APIs. No login, no proxy.

Input options

FieldNameRequiredWhat it does
packagesPackage namesnoPyPI package names to read, one per line, for example "requests" or "scikit-learn". A pypi.org/project/<name> link also works. Leave empty to use the 30 prefilled popular packages.
modeOutput modenopackages = one summary row per package. releases = one row per release published within the number of days below, newest first.
releasesWithinDaysNew releases window (days)noOnly used in releases mode. Keep releases published in the last N days.
includePrereleasesInclude pre-releasesnoKeep alpha, beta, release candidate and dev versions. Turn off to see stable releases only.
includeDownloadsInclude download countsnoAdd last day, last week and last month download counts from pypistats.org. Turn off for a faster run.
maxItemsMax rowsnoStop after this many rows. You pay only for rows delivered.

Limits, stated plainly

Public data only, no login. Fields a source does not publish come back empty rather than guessed. Coverage and freshness follow the underlying public source.
