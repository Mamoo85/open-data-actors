8-K Material Event Alerts: SEC 8-K Item Decoder

How it works

New SEC 8-K filings as an alert feed: every item decoded into plain English and ranked high, medium or low, with a severity filter and new-only monitor mode. Bankruptcy, cyber, restatement, delisting alerts. Also 10-K, IPO, full-text.

Input options

FieldNameRequiredWhat it does
formTypesForm typesyesSEC forms to return, one per line. Examples: 8-K, 10-K, 10-Q, S-1, F-1, 424B* (all final prospectuses), 13D, 13G, 6-K, 20-F, DEF 14A, S-4, 425, SC TO-T, NT 10-K. Shortcuts: IPO...
eightKItems8-K items (events)noOnly 8-K filings that report at least one of these items. Use codes or event names: 1.01 material agreement, 1.03 bankruptcy, 1.05 cybersecurity incident, 2.01 acquisition...
minSeverityMinimum event severitynoReturn only 8-K filings whose most serious item is at least this tier. Combine with 'Only new filings since last run' for a material-event alert feed. Any value other than 'any'...
tickersTickersnoOnly filings by these companies, by exchange ticker (AAPL, MSFT, BRK-B). Resolved to CIK with the official SEC ticker file. Leave empty for the whole market.
ciksCIK numbersnoOnly filings by these companies, by SEC Central Index Key (with or without leading zeros, e.g. 320193). Works for private and pre-IPO companies that have no ticker.
fullTextQueryFull-text phrasenoOptional. Search inside the filing text and exhibits with EDGAR full-text search, for example "going concern", "material weakness" or "artificial intelligence". Put a phrase in...
filedWithinDaysFiled within the last (days)noLook-back window counted back from today (or from the 'Filed to' date). Default 7 days.
filedFromFiled from (optional)noExact start date (YYYY-MM-DD). Overrides the look-back when set. EDGAR full-text search covers 2001 onward.
filedToFiled to (optional)noExact end date (YYYY-MM-DD). Default today.
includeAmendmentsInclude amendments (/A)noKeep amended filings such as 8-K/A and 10-K/A. Turn off to get original filings only.
onlyNewSinceLastRunOnly new since last run (monitor mode)noRemember every accession number delivered and skip it in later runs, so a scheduled run returns (and charges) only filings you have not received yet. Uses a named key-value store...
stateStoreNameMonitor state store namenoName of the key-value store that keeps the delivered accession numbers. Use a different name per schedule to keep separate watch lists.
maxItemsMax filingsnoStop after this many filings. Newest first (or most relevant first with a full-text phrase). You pay only for filings delivered.
maxApiRequestsMax SEC requestsnoSafety cap on requests to SEC per run (each search page holds 100 filings). Raise it for large backfills.
