How to get this yourself

  1. Open the Every URL in a sitemap, with an optional broken-link check actor on Apify.
  2. Give a site; get URLs from sitemaps with lastmod, depth and flags, and optionally status checks.
  3. Run it, then export the dataset as CSV, JSON or Excel from the results tab.

Limits, stated plainly

Sites without a sitemap return little. This page shows a small sample, so counts here say nothing about the whole dataset.
