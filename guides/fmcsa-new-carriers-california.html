How to get this yourself

  1. Open the New trucking companies, the week they get authority actor on Apify.
  2. Pick a state and days-back window; get new carriers with fleet size, driver count, operation type and, where FMCSA lists them, phone and email.
  3. Run it, then export the dataset as CSV, JSON or Excel from the results tab.

Limits, stated plainly

Contact fields are only as complete as the FMCSA record; some new carriers list no email. This page shows a small sample, so counts here say nothing about the whole dataset.
