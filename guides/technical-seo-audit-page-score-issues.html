How to get this yourself

  1. Open the Page-level technical SEO audit as data actor on Apify.
  2. Give URLs; get status, redirects, titles, meta, canonical, headings, hreflang and a score per page.
  3. Run it, then export the dataset as CSV, JSON or Excel from the results tab.

Limits, stated plainly

It audits the pages you list, not a full-site crawl. This page shows a small sample, so counts here say nothing about the whole dataset.
