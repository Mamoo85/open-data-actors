How to get this yourself

  1. Open the What is this website built on? actor on Apify.
  2. Paste a list of URLs; get detected technologies grouped by category, server and status per site.
  3. Run it, then export the dataset as CSV, JSON or Excel from the results tab.

Limits, stated plainly

Detection is from public HTML and headers, so server-only tech may be missed. This page shows a small sample, so counts here say nothing about the whole dataset.
