How to get this yourself

  1. Open the LinkedIn public job listings without a login actor on Apify.
  2. Give keywords and a location, with optional filters for date posted, remote or hybrid, experience level and job type; get one row per job with company, location, posted date, seniority, employment type, industries, salary when the posting shows it, and the full description.
  3. Run it, then export the dataset as CSV, JSON or Excel from the results tab.

Limits, stated plainly

Reads only the pages LinkedIn shows to logged-out visitors, with no profiles and no recruiter names. Public search returns at most about 1,000 results per query, so split large searches by location or date. Salary appears only when the posting publishes it. LinkedIn rate-limits anonymous traffic; if it keeps refusing, the run says so instead of returning invented rows. This page shows a small sample, so counts here say nothing about the whole dataset.
