How to get this yourself

  1. Open the Jobs from any Workday career site actor on Apify.
  2. Give company names or career URLs and optional keywords; get title, location, posted date, requisition ID and pay range when present.
  3. Run it, then export the dataset as CSV, JSON or Excel from the results tab.

Limits, stated plainly

Only public Workday sites; pay appears only if the posting lists it. This page shows a small sample, so counts here say nothing about the whole dataset.
