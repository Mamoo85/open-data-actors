How to get this yourself

  1. Open the WHOIS/RDAP, DNS, SSL and security headers in one call actor on Apify.
  2. Give domains; get registrar and age, nameservers, SPF/DMARC, SSL expiry and header score.
  3. Run it, then export the dataset as CSV, JSON or Excel from the results tab.

Limits, stated plainly

RDAP data varies by registry; some fields are redacted. This page shows a small sample, so counts here say nothing about the whole dataset.
