WordPress Plugin Stats: Installs, Updates, Health Score

How it works

Get WordPress plugin directory stats: active installs, rating, downloads, version, last updated, tested-up-to WordPress version, support thread resolution and a health score that flags abandoned plugins. Uses the public WordPress.org plugins API. No login, no proxy.

Input options

FieldNameRequiredWhat it does
browseDirectory listsnoWhich WordPress.org plugin directory lists to read. Plugins that appear in more than one list are returned once.
perListPlugins per listnoHow many plugins to read from each list (1 to 100).
slugsPlugin slugs (optional)noExtra plugins to look up by slug, one per line, for example "akismet" or "woocommerce". A wordpress.org/plugins/<slug>/ link also works.
searchSearch term (optional)noAlso read plugins matching this search in the directory, for example "seo" or "contact form".
minActiveInstallsMinimum active installsnoDrop plugins with fewer active installs than this. WordPress.org reports installs in steps (10, 100, 1000 and so on).
onlyAtRiskOnly plugins at risknoKeep only plugins whose abandonment risk is medium or high.
sortBySort rows bynoOrder of the output rows.
maxItemsMax rowsnoStop after this many rows. You pay only for rows delivered.

Limits, stated plainly

Public data only, no login. Fields a source does not publish come back empty rather than guessed. Coverage and freshness follow the underlying public source.
