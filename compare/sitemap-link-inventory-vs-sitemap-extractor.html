What the publisher says it does

Ours: Sitemap extractor that never fails on a bad file: nested indexes, .gz, .txt, lastmod, priority, images, hreflang. New: status-check toggle (404/redirect/noindex), depth limit, new-since-last-run monitor. Partial results, not errors. Pay per file or link checked.

apify: This Apify Actor extracts all URLs from a website's sitemaps and checks their status codes via lightweight HTTP requests. It provides a clean list of valid links, acting as an ideal pre-processor to ensure your larger crawling projects target only active URLs.
