DeFi TVL & Stablecoin Yield Monitor API (DefiLlama)

How it works

Screen DeFi protocols by chain, category and TVL change, filter stablecoin yield pools by minimum TVL and APY, and get alerts when thresholds are crossed since your last run. Beta.

Input options

FieldNameRequiredWhat it does
modeModenoProtocol TVL list, yield pool list, or alerts (compares to the previous run saved in a key-value store; the first alerts run only saves a baseline and is free).
chainsChainsnoKeep only these chains, e.g. Ethereum, Arbitrum, Solana (case-insensitive). Empty = all chains.
categoriesProtocol categoriesnoProtocols only. e.g. Lending, Dexs, Liquid Staking, Bridge. Empty = all.
protocolsSpecific protocolsnoProtocols only. DefiLlama slugs or names, e.g. aave-v3, lido. Empty = all.
minTvlUsdMinimum protocol TVL (USD)noProtocols only. Drop protocols with total value locked below this.
minChange1dPctMin 1-day TVL change (%)noProtocols only. e.g. 10 keeps protocols whose TVL rose 10% or more in a day.
maxChange1dPctMax 1-day TVL change (%)noProtocols only. e.g. -10 keeps protocols whose TVL fell 10% or more in a day.
minChange7dPctMin 7-day TVL change (%)noProtocols only.
maxChange7dPctMax 7-day TVL change (%)noProtocols only.
protocolSortBySort protocols bynoProtocols only.
maxItemsMax itemsnoCap on rows delivered (and charged) this run.
stablecoinOnlyStablecoin pools onlynoKeep only pools DefiLlama flags as stablecoin pools.
minPoolTvlUsdMinimum pool TVL (USD)noDrop thin pools below this TVL.
minApyMinimum APY (%)noKeep pools with APY at or above this.
