EU Public Tenders API: TED Search + Alerts

How it works

Search EU public procurement notices on TED by keyword, CPV code, country, buyer, date and value: deadline, estimated value, award winners, plus a new-notices-since-last-run monitor. Beta.

Input options

FieldNameRequiredWhat it does
keywordsKeywordsnoFull-text search over notice text. Any keyword matches (OR). Leave empty to filter only by the fields below.
cpvCodesCPV codesnoCommon Procurement Vocabulary codes. A short code is a prefix: 72 or 72000000 matches all IT services. Any code matches (OR).
countriesBuyer countriesnoCountry of the contracting authority, ISO 2-letter (DE, FR, PL) or 3-letter (DEU) codes. Empty = all EU/EEA.
buyerNameBuyer name containsnoContracting authority name, e.g. Bundesamt or Ministry of Health.
noticeKindNotice kindnoContract notices carry deadline and estimated value. Award notices carry winners and awarded value.
daysBackPublished in the last N daysnoPublication-date window (1 to 365).
maxItemsMax itemsnoCap on notices delivered (and charged) this run.
onlyNewSinceLastRunMonitor mode: only new since last runnoSkip notices delivered in a previous run (tracked in a named key-value store). A repeat run with no new notices delivers 0 rows and charges 0 events.
onlyOpenForBidsOnly tenders still open for bidsnoContract notices only: keep notices whose submission deadline has not passed.
minValueMinimum valuenoMinimum estimated value (contract notices) or awarded value (award notices), in the notice currency. Notices without a published value are dropped when a value filter is set.
maxValueMaximum valuenoMaximum estimated or awarded value.
currencyValue currencynoOptional ISO currency code (EUR, PLN, SEK). When set, only notices valued in that currency pass the value filter.
stateStoreNameDedupe store namenoNamed key-value store that remembers delivered notices. Change it to keep separate monitors or reset dedupe.

Limits, stated plainly

Public data only, no login. Fields a source does not publish come back empty rather than guessed. Coverage and freshness follow the underlying public source.
