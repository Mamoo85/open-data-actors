NPI Registry Scraper: New Healthcare Organizations

How it works

New and changed healthcare organizations (NPI type 2: clinics, pharmacies, home health, DME suppliers, labs) from the official CMS NPPES NPI Registry, with taxonomy, practice address and phone. Organizations only. No API key; new-only monitor mode.

Input options

FieldNameRequiredWhat it does

organizationCategoriesOrganization categoriesnoKeep only these categories (derived from the primary taxonomy code). Leave empty for all.

Limits, stated plainly

Public data only, no login. Fields a source does not publish come back empty rather than guessed. Coverage and freshness follow the underlying public source.
