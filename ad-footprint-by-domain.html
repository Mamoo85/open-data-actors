Competitor Ads Checker: Google + Meta Ad Library

How it works

Check whether a company is advertising: ad counts, formats, platforms, first and last seen, regions and sample ads from Google Ads Transparency Center and Meta Ad Library, with a 0-100 footprint score.

Input options

FieldNameRequiredWhat it does
domainsDomainsnoCompany domains to check, one per line (for example "hubspot.com"). Website URLs work too; the domain is taken from them.
startUrlsWebsite URLs (paste)noPaste company website URLs (homepages, landing pages). Each URL's domain is checked once. Same as Domains, in the format other actors use.
brandNamesBrand names (optional, same order as Domains)noOverride the brand keyword used to find the advertiser in the Meta Ad Library, in the same order as Domains (for example "Blue Bottle Coffee" for bluebottlecoffee.com). Leave...
sourcesAd librariesnoWhich public ad libraries to check. LinkedIn is reported as unavailable (its robots.txt forbids automated access), with a link to check by hand.
countryCountrynoTwo-letter country code where the ads were shown (US, GB, DE, ...), or ANY for all countries.
includeAdSamplesAd samples per librarynoHow many sample ads to attach per library (text, dates, preview link). The first 3 per library are included in the domain price; more cost the ad-sample event each.
maxItemsMax domainsnoStop after this many domains.
onlyNewOnly changed since last run (monitor)noMonitor mode: output (and charge) only domains whose ad counts or newest ads changed since the last run that used the same state store. The first run outputs everything.
stateStoreNameState store namenoNamed key-value store that remembers the last snapshot per domain for monitor mode. Use one name per watch list.
proxyConfigurationProxynoMeta rate-limits datacenter IPs, so residential Apify Proxy is the default. Google is called directly and falls back to this proxy.

Limits, stated plainly

Public data only, no login. Fields a source does not publish come back empty rather than guessed. Coverage and freshness follow the underlying public source.
