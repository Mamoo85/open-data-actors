Apple Podcasts Scraper: Active Shows, Charts & Cadence

How it works

Find active Apple Podcasts shows by keyword, chart or genre. Each row adds real activity from the show RSS feed: last episode, cadence, episodes per 90 days and a 0-100 activity score. No emails, no login, no API key.

Input options

FieldNameRequiredWhat it does
searchTermsSearch termsnoKeywords searched in the Apple Podcasts directory (show title, publisher and topic), for example marketing, saas, true crime. Each term returns up to 200 shows per country.
chartGenresApple charts (genres)noRead the Apple Podcasts top chart for these genres in every selected country. All podcasts = the overall Top Shows chart. Each show keeps its chartRank.
chartLimitShows per chartnoHow many chart positions to read per genre and country (1-200; the overall Top Shows chart allows up to 100, larger values use the classic chart feed).
appleIdsApple ids or URLsnoSpecific shows to check, as Apple ids (1200361736) or Apple Podcasts URLs (https://podcasts.apple.com/us/podcast/the-daily/id1200361736). Useful for tracking a watch list.
countriesCountriesnoApple storefronts as 2-letter codes, for example us, gb, ca, au, de. Search and charts run per country.
onlyActiveOnly active showsnoReturn only shows whose newest episode is within the active window below. Turn off to also get dormant shows (they get isActive = false).
activeWithinDaysActive within (days)noA show is active when its newest episode was published within this many days (1-3650).
minEpisodesMinimum episodesnoSkip shows with fewer episodes than this (Apple episode count). 0 = no filter.
languageLanguagenoKeep only shows whose feed declares this language, for example en, es or pt-br (prefix match: en also matches en-us). Leave empty for any language.
excludeExplicitExclude explicit showsnoSkip shows Apple or the feed marks as explicit (brand-safety filter for sponsors).
includeFeedActivityRead RSS feeds for activitynoRead each show public RSS feed (newest 400 KB) to measure last episode, cadence and episodes per 30/90 days. Turn off for a faster Apple-only run (activity then uses the Apple...
onlyNewSinceLastRunOnly new since last runnoMonitor mode: skip shows delivered in an earlier run (remembered by Apple id in a named key-value store). A repeat run on the same input charges only for new shows.
stateStoreNameMonitor store namenoNamed key-value store that remembers delivered shows. Use a different name per watch list.
maxItemsMax showsnoMaximum podcast rows delivered (and charged) this run. Rows are delivered in source order (your ids, chart rank, then search relevance).

One row per result. These are the 37 fields declared in the actor's dataset schema (field list from the schema, not a sample run).

Limits, stated plainly

Public data only, no login. Fields a source does not publish come back empty rather than guessed. Coverage and freshness follow the underlying public source.
