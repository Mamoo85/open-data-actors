Contractor License Lookup and Verification API (6 States)

How it works

Verify and monitor contractor and trade licenses from official state open-data portals (WA, TX, CT, CO, OR, DE): status, expiration, address and phone where published. Filter by trade, city, ZIP, name or number.

Input options

FieldNameRequiredWhat it does
modeModenosearch: find licenses by trade, location, name or number. verify: one output row per item in the verify list, with found / not found. new_licenses: licenses issued or registered...
statesStatesnoWhich state datasets to query. Empty = all 6 states. Oregon has two sources (CCB construction contractors and BCD electrical, plumbing, boiler and elevator licenses).
tradeTradenoNormalized trade. States whose license types cannot express this trade are skipped (listed in the OUTPUT summary). Leave empty for all trades.
cityCitynoExact city name as published (case-insensitive), for example Seattle or Austin.
zipZIP codenoZIP or ZIP prefix, for example 98101 or 981.
countyCountynoCounty name without the word County, for example Harris. Only Texas and Oregon publish county; other states are skipped when this is set.
maxResultsMax resultsnoMaximum license records to return across all states (split fairly across states first, then topped up). Ignored in verify mode, which returns one row per input.
businessNameBusiness name keywordsnoOne keyword per line. A record matches if any keyword matches; within a keyword every word must appear in the business or DBA name. Example: smith roofing.
personNamePerson name keywordsnoOne per line. Matches licensee or principal / responsible person names (word order does not matter). Example: john smith.
licenseNumberLicense numbernoExact license number, for example 4WALLWD781M5 (WA), HIC.0702746 (CT), 100836 (CO).
activeOnlyActive licenses onlynoKeep only licenses whose status is active AND whose expiration date has not passed.
contractorsOnlyContractor licenses onlynoKeep only business / contractor-level licenses and drop individual journeyman, apprentice and technician licenses.
daysBackDays back (new_licenses mode)nonew_licenses mode: licenses issued in the last N days.
expiringWithinDaysExpiring-soon window (days)noisExpiringSoon is true when the license expires within this many days.

Limits, stated plainly

Public data only, no login. Fields a source does not publish come back empty rather than guessed. Coverage and freshness follow the underlying public source.
