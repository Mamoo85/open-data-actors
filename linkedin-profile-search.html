LinkedIn Candidate Sourcing List Builder, No Login

How it works

Build candidate and prospect lists from public LinkedIn profiles by job title, location, company, school or industry. Short mode returns name, headline, title, company, location and profile URL. No login.

Input options

FieldNameRequiredWhat it does
searchQuerySearch query (free text)noAny words to match on the profile, e.g. "Salesforce admin" or "founder fintech". Combined with the filters below.
currentJobTitlesJob titlesnoJob titles to search for. Each title is searched separately (and combined with each location / company).
locationsLocationsnoCities, metro areas, states or countries, e.g. "Detroit", "Austin, Texas", "Germany".
currentCompaniesCompaniesnoCompany names, e.g. "Ford Motor Company". Matches people who list that company.
schoolsSchoolsnoSchools or universities, e.g. "University of Michigan".
industriesIndustries / keywordsnoIndustry words or skills, e.g. "SaaS", "healthcare", "PPC".
firstNamesFirst namesnoFind people by first name (combine with last names to look up a specific person).
lastNamesLast namesnoFind people by last name.
fillMissingDetailsFill missing location and follower countsnoWhen the fast search route returns profiles without location or follower counts, re-read that page through Google directly (up to 40 s per page) to fill them in.
profileScraperModeProfile detailnoFull reads each public profile page. If LinkedIn refuses one, that row comes back with the search data and is charged the short price.
maxItemsMax profilesnoHard cap on profiles (and cost) for the whole run.
maxSearchPagesPerQueryGoogle pages per searchnoEach search is asked up to this many times with different recency and country settings to find more people (about 10 profiles per page). The actor stops early when pages stop...
onlyNewMonitor mode: only new profilesnoRemembers profiles already delivered (named key-value store) and returns only new ones next run. Already-seen profiles are not charged. Schedule it weekly.
monitorStoreNameMonitor store namenoUse a different name per saved search.

Limits, stated plainly

Public data only, no login. Fields a source does not publish come back empty rather than guessed. Coverage and freshness follow the underlying public source.
