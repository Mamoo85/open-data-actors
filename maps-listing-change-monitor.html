Google Maps listing change monitor: ratings, hours and closures

Who it is for: Local-SEO agencies, franchise and multi-location owners, and sales teams who react to changes at nearby businesses.

The problem

Listings change quietly: ratings move, hours change, places close. Spotting that across 200 listings by re-checking Maps is not realistic.

How it works

Run it on a saved set of places over time. Each run compares against the last and returns events with type, severity and a plain-English summary, plus old and new values, rating and review deltas and review velocity.
