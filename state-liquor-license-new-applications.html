Liquor License Leads: New Applications in NY, TX, MO

How it works

Track new liquor license applications and pending records from official NY, TX and MO open-data portals to find bars and restaurants about to open. Each record has dates, address, venue category and a lead score in one schema, with state filters. No login, no proxy.

Input options

FieldNameRequiredWhat it does
statesStatesnoTwo-letter state codes to read. Supported: NY (pending applications and new licenses), TX (new TABC licenses), MO (new licenses). Leave empty for all.
recordKindRecord kindnoapplication = filed but not yet approved (best lead timing; NY only). issued = a license that was recently granted.
licenseTypeContainsLicense type containsnoKeep records whose license type contains at least one of these words (case-insensitive). Example: ["restaurant", "tavern", "mixed beverage"]. Leave empty for all types.
countyOrCityContainsCounty or city containsnoKeep records whose city or county contains this text. Example: "Brooklyn" or "Harris". Leave empty for everywhere.
newSinceDaysFiled or issued within (days)noKeep records whose application or issue date is within the last N days.
onlyNewSinceLastRunOnly records not seen in earlier runsnoMonitor mode. Skips records that an earlier run of this Actor already delivered, so a weekly schedule returns only fresh leads.
maxItemsMax recordsnoStop after this many records, highest lead score first. You pay only for records delivered.
