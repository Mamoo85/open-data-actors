EU Company Registry API: KYB Lookup, Pay per Result

How it works

Verify a company or build a feed of newly registered companies from official registers in France, Norway and Finland: registry ID, legal form, status, registration date, address, industry code, source link. No login. Beta.

Input options

FieldNameRequiredWhat it does
queriesCompany names or registry IDsnoKYB lookup mode: company names or registry numbers (French SIREN/SIRET, Norwegian 9-digit org number, Finnish business ID like 0112038-9). Leave empty for the new-registrations...
countriesCountriesnoRegisters to query. Empty = all three. France supports lookup only (its open API has no creation-date filter).
daysBackDays back (new-registrations mode)noReturn companies registered in the last N days (1 to 60). Ignored in lookup mode.
keywordsName keywords (new-registrations mode)noKeep only new companies whose name contains any of these words, e.g. consulting, bygg, rakennus.
maxItemsMax itemsnoCap on company records delivered (and charged) this run.
resultsPerQueryResults per query and countrynoLookup mode: how many best matches to return per query and country.
activeOnlyActive companies only (new-registrations mode)noDrop bankrupt, liquidating or dissolved entities from the new-registrations feed.
onlyNewSinceLastRunOnly new since last run (deduped)noNew-registrations mode: skip companies delivered in a previous run (tracked in a named key-value store). A repeat run delivers 0 rows and charges 0 events.
stateStoreNameDedupe store namenoNamed key-value store that remembers delivered companies. Change it to keep separate feeds or reset dedupe.

Limits, stated plainly

Public data only, no login. Fields a source does not publish come back empty rather than guessed. Coverage and freshness follow the underlying public source.
