SSL Certificate Subdomain Finder: Subdomains from CT Logs

How it works

Find every subdomain of a domain with this SSL certificate finder, which searches public Certificate Transparency logs. Each hostname comes with first seen, last seen, expiry, issuer, certificate count and a freshness score. No login, no proxy.

Input options

FieldNameRequiredWhat it does
domainsDomainsnoDomains to look up, for example example.com. Subdomains of each domain are found from public certificate logs. A full URL also works. Leave empty to use the two example domains.
hostnameContainsHostname containsnoKeep hostnames that contain at least one of these words (case-insensitive). Example: ["staging", "dev", "admin", "vpn"]. Leave empty for all hostnames.
newWithinDaysFirst seen within (days)noKeep only hostnames whose first certificate was issued in the last N days. Good for spotting new services. 0 = no limit.
statusFilterCertificate statusnoactive keeps hostnames whose newest certificate has not expired. expiring_soon keeps those that expire within 30 days.
includeExpiredInclude expired certificatesnoTurn off to read only certificates that are still valid. Hostnames that only ever had expired certificates are then missing.
maxItemsMax hostnamesnoStop after this many hostnames. You pay only for hostnames delivered.

Limits, stated plainly

Public data only, no login. Fields a source does not publish come back empty rather than guessed. Coverage and freshness follow the underlying public source.
