ClinicalTrials.gov New Studies Tracker: Clinical Trials API

How it works

ClinicalTrials.gov new studies tracker: get newly registered clinical trials from the free ClinicalTrials.gov API with NCT id, title, sponsor, phase, status, conditions, interventions, enrollment, dates, countries and an opportunity score, plus an optional sponsor rollup. No login.

Input options

FieldNameRequiredWhat it does
daysBackFirst posted in the last (days)noKeep studies whose first-posted date on ClinicalTrials.gov falls in the last N days.
searchTermSearch termnoOptional ClinicalTrials.gov search expression, for example "diabetes" or "KRAS inhibitor". Leave empty for all conditions.
phasesPhasesnoOptional. Keep only these study phases. Leave empty for all.
statusesOverall statusnoOptional. Keep only these statuses. Leave empty for all.
minOpportunityScoreMinimum opportunity scorenoOptional 0 to 100. Keep only rows at or above this score.
sponsorRollupSponsor rollupnoTurn on to get one row per lead sponsor (study count, phases, top conditions, total enrollment, best score) instead of one row per study.
maxItemsMax rowsnoStop after this many rows, best opportunity score first. You pay only for rows delivered.

Limits, stated plainly

Public data only, no login. Fields a source does not publish come back empty rather than guessed. Coverage and freshness follow the underlying public source.
