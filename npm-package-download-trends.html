npm Package Download Trends and New Versions API

How it works

Get npm package download trends and new versions: weekly and 30-day downloads, trend percent, latest version, publish date, deprecation, maintainers and a momentum score for every package you list. Uses the public npm registry and download APIs. No login, no proxy.

Input options

FieldNameRequiredWhat it does
packagesPackage namesnonpm package names to read, one per line, for example "react" or "@angular/core". An npmjs.com/package/<name> link also works. Leave empty to use the 35 prefilled popular packages.
modeOutput modenopackages = one summary row per package. versions = one row per version published within the number of days below, newest first.
versionsWithinDaysNew versions window (days)noOnly used in versions mode. Keep versions published in the last N days.
includePrereleasesInclude pre-releasesnoKeep versions with a pre-release tag such as -beta.1 or -rc.2 (versions mode). Turn off to see stable versions only.
includeDownloadsInclude download countsnoAdd day, week and 30-day download counts and the trend from api.npmjs.org. Turn off for a faster run.
maxItemsMax rowsnoStop after this many rows. You pay only for rows delivered.

Limits, stated plainly

Public data only, no login. Fields a source does not publish come back empty rather than guessed. Coverage and freshness follow the underlying public source.
