SAM.gov contract opportunities as a clean feed

Who it is for: Small businesses and new government contractors, capture and bid teams, proposal consultants, and GovCon tools that need a structured feed.

The problem

SAM.gov is the official source for federal bids, but finding new ones in your niche means saving searches and checking them by hand.

How it works

Give keywords and optional filters (notice type, NAICS code, set-aside, state, dates). It runs the search, opens each notice, and returns one row with the full description as plain text, agency and office, notice type, posted date, response deadline, NAICS and set-aside. Attachments can be listed on request. With the new-only option, notices you already received are skipped and not charged, so a daily schedule becomes a feed of new bids.

Limits, stated plainly

Only what SAM.gov publishes on each notice. Contacts are the government points of contact on the notice, not company contacts. The default keyless source is the JSON interface the SAM.gov website uses; it is not a documented API and may change, and the run stops with a plain message if it does. You can use the official API with your own key instead. Keyword search also matches text inside attached documents unless you set it to title only.
