Remote jobs from 6 job boards in one deduped table

Who it is for: Remote job seekers and job-alert newsletters, niche remote job boards, recruiters, salary researchers, sales teams that sell to hiring companies, AI agents.

The problem

Remote jobs are spread over many boards, each with its own format, and the same job is often posted on three of them.

How it works

One run reads the official public APIs and feeds of Remotive, Remote OK, We Work Remotely, Himalayas, Jobicy and Arbeitnow; merges the same job across boards (other listings go to alsoListedOn); parses salary into min, max, currency, period and yearly USD; and maps every job to the same categories, job types, experience levels, regions and timezones. Filter by keywords, salary, category, seniority, region, timezone, posting date and company; monitor mode returns only jobs you have not seen.

Limits, stated plainly

Only what each board publishes in its public API or feed: the newest jobs, not full archives (a full run returns a few hundred unique jobs). Each board is called no more often than it allows, and responses are cached per account, so runs within the hour return the same jobs. Remotive jobs are delayed 24 hours. Category, level and region are inferred from the title and location text when a board does not give them. Republishing must follow the attribution rule of each board (link to sourceUrl, name the board).
